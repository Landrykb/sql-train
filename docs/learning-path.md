# BESA Learning Paths

## Business Retail
Analyse supermarket sales to uncover revenue, profit, and return drivers.


1. **Inspect Sales Rows** — skills: `select, where, order`
2. **Total Revenue by Product** — skills: `group, sum`
3. **Returns vs Sales** — skills: `join`
4. **Running Monthly Revenue** — skills: `window`
5. **Profit After Cost** — skills: `cte`
6. **Capstone: Return Drivers** — skills: `subquery, case`

2. **Avg NDVI by Region** — skills: `group, avg`
3. **NDVI vs Yield Join** — skills: `join`
4. **NDVI Rolling Trend** — skills: `window`
5. **Yield Gap CTE** — skills: `cte`
6. **Capstone: Drivers of Yield Gap** — skills: `subquery, case`
